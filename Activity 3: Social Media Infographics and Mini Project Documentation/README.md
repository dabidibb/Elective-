# Activity 3 — Social Media Infographics and Mini Project Documentation

**Course:** GE 4120 — The 21st Century IT Skills

## About this activity
This activity focuses on creating a social media infographic and documenting the work done for a mini project.

## Activity outputs
- [Social media infographic](Infographic_MALOTO.png)
- [Mini project documentation](Project%20documentation_MALOTO%20%281%29.pdf)

## What have I learned?
I learned how to present information in a way that people can understand quickly. I also learned that documenting a project is important because it shows the steps and results of the activity. One challenge in making an infographic is deciding what information to include without putting too much text. I can improve by keeping the main message clear and reviewing the layout carefully. These skills can help me make health awareness posts and educational materials in the future.
