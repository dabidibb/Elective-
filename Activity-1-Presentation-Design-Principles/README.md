## About this activity
This activity focuses on the basic principles of presentation design and how to make a presentation clear, organized, and easy to understand.

## What have I learned?
I learned that a good presentation should be easy to read and follow. I learned to pay attention to the arrangement of text and images so the message is clear. One challenge in designing a presentation is keeping it attractive without making it too crowded. I can improve by checking the spacing, text size, and layout before submitting my work. I can use these skills when making class presentations and health education materials.
