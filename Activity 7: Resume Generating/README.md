# Activity 7: Resume Generating

**Course:** GE 4120 — The 21st Century IT Skills

## About this activity
I used ChatGPT and Claude AI to create a one-page nursing student resume from the same personal information. I compared their outputs based on structure, clarity, formatting, and overall quantity.

## Comparison summary
| Criteria | ChatGPT | Claude AI |
|---|---|---|
| Structure | Organized into clear resume sections | Organized and includes a Core Competencies section |
| Clarity | Clear text and headings | Simple and easy-to-read layout |
| Formatting | More decorative, with navy blue elements and icons | Plain white, traditional resume layout |
| Overall quantity | Includes the main resume information | Includes an additional competencies section |

## What have I learned?
I learned that different AI tools can give different results even when they receive the same task. ChatGPT created a more creative resume design, while Claude AI used a simpler design with more information. One challenge was deciding which result was better without judging only by appearance. I compared the structure, clarity, formatting, and completeness of both resumes to make a fair evaluation. In the future, I can use AI tools to help prepare documents while still checking the results myself.
