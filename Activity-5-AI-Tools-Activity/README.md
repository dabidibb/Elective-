# Activity 5: AI Tools Activity

**Course:** GE 4120 — The 21st Century IT Skills

## About this activity
For this activity, I used ChatGPT to create an image. I started with a simple prompt about a boy fishing and then improved my prompt by adding more specific details. I compared the original and improved results.

## What I did
1. Used the original prompt: “create me a picture of a boy sail fishing.”
2. Wrote a clearer prompt describing a lonely boy sitting on one moon while fishing, with bright stars and a wide animated-style space background.
3. Compared the two pictures based on their style, details, and meaning.

## What have I learned?
I learned that the words I use in an AI prompt can greatly affect the result. My first prompt was too simple, so the image did not fully show what I wanted. I improved it by adding details about the boy, the moon, the stars, and the background. The improved picture matched my idea better and showed more emotion. I can use this skill when creating images or educational materials with AI in the future.
